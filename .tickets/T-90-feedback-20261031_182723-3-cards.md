# Ticket T-90-feedback-20261031_182723-3: Card Sprites, Ranks/Pips, Contrasting Black Suits, Centered Trump Indicator, Card Backs & Table Textures

## Subsystem
Frontend Card Components & Visual Assets (`frontend/src/components/`, `frontend/src/styles/`)

## Wave
WAVE:1 (Runs concurrently with Wave 1 Backend and Audio tickets)

## Description & User Requirements
Overhaul card rendering, pip distribution, rank iconography, trump badge centering, card back patterns, and table texture definitions:
1. **Contrasting Black Suits (Feedback Item 2)**:
   - In `frontend/src/components/Card.tsx`, update `suitColor` for spades and clubs from grey (`#bababa`) to a sharply contrasting, deep black (`#111111` or `#0a0a0a`). Red suits (hearts and diamonds) remain rich red (`#c33` or `#dc2626`).
2. **Card Sprites & Pip Distribution (Feedback Item 3)**:
   - For ranks 2 through 10: render the number of suit pips equal to the rank, laid out symmetrically across the card face matching standard playing card pip arrangements (e.g. 2 vertical pips for 2; 3 vertical pips for 3; 4 corner pips for 4; 4 corners + 1 center for 5, etc.).
   - For Aces: render a single large, ornate suit pip centered on the card with a total width equal to approximately half of the card width (~35px on a 70px viewBox).
   - For Face Cards (Jack, Queen, King): render the letters 'J', 'Q', and 'K' respectively as prominent decorative centerpieces, surrounded by decorative suit pips arranged around the letter.
   - Maintain corner rank labels and mini-suit pips in top-left and bottom-right corners.
3. **Centered Trump Indicator (Feedback Item 4)**:
   - Ensure the trump badge on trump cards has the suit symbol perfectly centered horizontally and vertically inside the yellow/gold circle badge.
4. **Card Sizing & Drop Target Outlines (Feedback Item 5)**:
   - Increase overall card dimensions when viewport permits (e.g., base dimensions increased from 70x100 to 80x114 or 84x120 while preserving scalable SVG viewBox `0 0 70 100`).
   - Ensure all drop outlines and target placeholders (`[data-testid^="target-outline-"]`, redirect outlines, etc.) strictly match the exact width and height of the cards.
5. **6 Card Back Patterns (Feedback Item 10)**:
   - Expand `CardBack.tsx` to support 6 distinct SVG/CSS pattern variations selectable via a `pattern` prop or global theme:
     1. `classic-hatch`: 45-degree cross-hatching.
     2. `royal-diamond`: Repeating geometric diamond lattice.
     3. `celtic-weave`: Interlocking knotwork lines.
     4. `hex-mesh`: Modern honeycomb hexagonal pattern.
     5. `chevron`: Elegant zigzag herringbone weave.
     6. `starburst`: Radiant geometric starburst motif.
6. **6 Table Textures (Feedback Item 9 Asset Support)**:
   - Create a texture definition module (`frontend/src/styles/tableTextures.ts` or CSS rules in `frontend/src/styles/table.css`) defining at least 6 distinct table felt textures matching the game aesthetic:
     1. `emerald-felt`: Classic dark green billiard felt.
     2. `midnight-navy`: Deep royal navy blue baize.
     3. `burgundy-velvet`: Rich wine-red table felt.
     4. `charcoal-slate`: Dark neutral carbon felt.
     5. `forest-moss`: Subtle earthy deep-moss texture.
     6. `vintage-oak`: Subtle dark woodgrain tabletop.
   - Provide CSS variables/classes supporting dynamic Brightness, Contrast, and Hue filter adjustments.

## Acceptance Criteria
- [ ] Black suit pips and text render in sharp black (`#111111`), never muted grey.
- [ ] Cards 2–10 show exactly N suit pips on the card face matching their rank.
- [ ] Aces display a single ornate suit pip spanning ~50% of the card width.
- [ ] Face cards (J, Q, K) render prominent central rank letters flanked by decorative suit pips.
- [ ] Trump badges have their suit symbol centered exactly within the circular yellow badge.
- [ ] `CardBack` renders 6 distinct selectable patterns.
- [ ] Table texture presets are defined and support CSS filter controls (brightness, contrast, hue).
- [ ] Target drop outlines match the card dimensions with zero spatial distortion.
- [ ] Unit tests in `frontend/src/__tests__/Card.test.tsx` and `frontend/src/__tests__/GameTable.test.tsx` pass.
