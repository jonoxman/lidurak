# T-96-visual-qa-20261122_183753-1: Fix Left-Sidebar PLAYERS Text Overlap and Covered Table `'10'` Rank Clipping

## Problem Summary
Real Chromium visual inspection of `.reviews/screenshots/` revealed two objective visual/layout bugs:

1. **Left-Sidebar `PLAYERS` Row Text Overlap (`Alice (You)` overlaps `N cards`):**
   - Visible in every game screenshot (`step_2_item_2_6card_alice.png`, `step_7_item_5_14card_expand.png`, `step_8_item_5_30card_compress.png`, `step_9_item_6_single_card_hover_no_part.png`, etc.).
   - `Alice (You)` in Column 1 of `.status-badge` overflows horizontally across Column 2 (`.status-cards`), rendering directly on top of `6 cards` / `14 cards` / `30 cards` / `1 cards`.
   - **Root Cause:** `.game-shell` allocates `240px` to `.sidebar-left`, and `.status-badge` (`frontend/src/app.css`) uses `grid-template-columns: minmax(0, 1fr) auto minmax(0, 1fr); gap: 8px;`, squeezing Column 1 to ~`64px` even when Column 3 (`.status-state-slot`) is empty. Meanwhile `.status-player` has `justify-self: start` without `max-width: 100%; overflow: hidden;` (and `frontend/src/styles/table.css` redeclares `.status-player` without overflow clipping), and `.status-name` lacks `min-width: 0`, allowing `.status-player` to spill out of Column 1 over `.status-cards`.

2. **Table Pair Defense Card Clips the `'0'` of `'10'` (Item #2 Regression):**
   - Visible in `step_2_item_2_6card_alice.png` and all `qa-normal-6-actions` screenshots (`step_3`, `step_4`, `step_5`, `step_6`, `step_10`, `step_12`, `step_14`).
   - On the table bout pair `10♠` covered by `J♠`, the covering card (`J♠`) is offset by `--pair-defense-offset: 20px` (`frontend/src/styles/table.css`), which is narrower than `CARD_INDEX_STRIP_WIDTH_PX` (`36px`). As a result, `J♠` covers the right half (`0`) of the full-size `10` rank on `10♠`, violating Item #2 (*"Make sure to adjust the maximum card overlap in the hand and other places to ensure the full rank of the card is always visible"*).

## Required Changes

### 1. Fix `PLAYERS` Row Overlap & Readability
- **`frontend/src/app.css`:**
  - Keep `.status-badge`'s three-track structure (`grid-template-columns: minmax(0, 1fr) auto minmax(0, 1fr)`) so existing layout contract tests (`frontend/src/__tests__/GamePage.test.tsx`) remain satisfied, while tightening internal spacing (`gap: 6px;`) if helpful.
  - Widen the left sidebar column in `.game-shell` (e.g., from `240px` to `272px` or `280px` on desktop) so `Alice (You)` fits cleanly in Column 1 without truncation alongside `N cards` and status tags.
  - On `.status-player`, add `max-width: 100%; overflow: hidden;` (with `min-width: 0;`) so a long player name can never overflow Column 1 into `.status-cards`.
  - On `.status-name`, add `min-width: 0; flex: 1 1 auto;` alongside `overflow: hidden; text-overflow: ellipsis; white-space: nowrap;`.
- **`frontend/src/styles/table.css`:**
  - Ensure the `.status-player` rule around line 2103 also preserves `max-width: 100%; overflow: hidden;` (or does not weaken the `app.css` containment).

### 2. Clear the Full `'10'` Index Strip on Covered Table Pairs
- **`frontend/src/styles/table.css`:**
  - Update `.table-pair` to `--pair-defense-offset: var(--card-index-strip-width, 36px);` and update the fallback in `padding: 0 var(--pair-defense-offset, 36px) var(--bout-card-offset, 18px) 0;` and `.table-pair-defense { margin: 15px 0 0 var(--pair-defense-offset, 36px); }` so the covering defense card clears the entire `36px` corner index strip of a covered `10` card.
  - In `@media (max-width: 899px)`, update `.table-pair` `--pair-defense-offset: 18px;` (proportional to the `48px` mobile card: `ceil(36 * 48 / 100) = 18px`) and its `padding` / `.table-pair-defense` fallback to `18px`.
- **`frontend/src/components/GameTable.tsx`:**
  - Update `BOUT_DEFENSE_OVERHANG_RATIO` from `0.25` to `0.36` so `boutLayout` accounts for the full `36px` defense overhang when spacing adjacent table pairs.
