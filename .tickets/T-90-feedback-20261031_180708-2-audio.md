## Detailed Technical Specifications

### 1. Sound Pack Definitions (`frontend/src/audio/SoundEngine.ts`)
Define 5 named sound packs with cohesive procedural synthesis parameters:
1. **Classic Felt:** Organic, subtle acoustic card slides, soft felt thuds, wooden taps, gentle woodblock tick.
2. **Wood & Brass:** Resonant acoustic warmth, brass bell chimes, warm metallic clicks, low marimba tick.
3. **Arcade 8-Bit:** Retro square-wave and noise synthesis, 8-bit blips, retro game positive/negative arpeggios, crisp retro pulse tick.
4. **Minimal Crisp:** Ultra-clean modern UI clicks, sine pop covers, airy swooshes, high-frequency subtle pip tick.
5. **Synthwave:** FM-modulated synthesizer chords, neon laser sweeps, punchy analog-style electronic beats, resonant retro-wave clock pulse.

### 2. Supported Game Actions
Each sound pack must synthesize distinctive audio for:
- `attack`: Initiating an attack card onto the table.
- `defend`: Successfully covering an attack.
- `pass`: Attacker or throw-in player passing turn.
- `surrender`: Defender surrendering / taking cards.
- `redirect`: Transferring defense to the next player.
- `snap`: Drag hover magnetic snap.
- `error`: Invalid card drop or disallowed action.
- `tick`: Turn clock warning tick when time remaining is strictly under 5 seconds.

### 3. Web Audio Synthesis Architecture
- Synthesize all sounds procedurally using `AudioContext`, `OscillatorNode`, `GainNode`, and `BiquadFilterNode` (avoid external `.mp3`/`.wav` assets to guarantee zero network latency and no missing file 404s).
- Maintain user-specific settings in `localStorage` under `lidurak_audio_settings`:
  ```ts
  export interface AudioSettings {
    pack: 'classic' | 'wood' | 'arcade' | 'minimal' | 'synthwave';
    volume: number; // 0.0 to 1.0, default 0.7
    muted: boolean;
  }
  ```
- Expose methods:
  - `setVolume(vol: number): void`
  - `getVolume(): number`
  - `setPack(packId: string): void`
  - `getPack(): string`
  - `getAvailablePacks(): { id: string; name: string }[]`
  - `play(action: 'attack' | 'defend' | 'pass' | 'surrender' | 'redirect' | 'snap' | 'error'): void`
  - `playTick(secondsRemaining: number): void` (synthesizes ticking pitch matching the urgency of the remaining seconds: 4s, 3s, 2s, 1s)
