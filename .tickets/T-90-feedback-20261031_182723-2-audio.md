# Ticket T-90-feedback-20261031_182723-2: Web Audio Synthesizer Engine & 5 Cohesive Sound Packs

## Subsystem
Frontend Audio Engine (`frontend/src/audio/`)

## Wave
WAVE:1 (Runs concurrently with Wave 1 Backend and Card Visuals tickets)

## Description & User Requirements
Implement a versatile, zero-asset Web Audio API synthesizer system supporting 5 distinct sound packs and critical turn timer audio:
1. **5 Cohesive Sound Packs (Feedback Item 7)**:
   - Create 5 named sound packs implemented purely via Web Audio API oscillators, gain envelopes, and filters (no external audio files):
     1. **"Classic Felt"**: Organic physical card flicks, soft felt thuds, and wooden table taps.
     2. **"Arcade 8-Bit"**: Chiptune square-wave arpeggios, vintage game blips, and retro victory jingles.
     3. **"Sci-Fi Synth"**: Smooth resonant FM sweeps, futuristic UI chirps, and ambient frequency glides.
     4. **"Acoustic Pluck"**: Warm resonant string/bell tones, pentatonic acoustic chime taps.
     5. **"Modern Minimal"**: Subtle, muted UI pops, soft high-passed clicks, and deep low-frequency sub-thumps.
   - For every sound pack, define sound designs for ALL game events:
     - `cardPlay` (initial attack or throw-in)
     - `cardDefend` (covering an attack)
     - `cardRedirect` (transferring the attack)
     - `pass` (passing the bout)
     - `surrender` (taking table cards)
     - `boutWon` (successful defense / discard)
     - `gameWin` / `gameDurak` (bout and match conclusions)
     - `invalid` (illegal action attempt)
     - `clockTick` (timer pulse under 5s)
   - Keep styles strictly cohesive within each pack (do not mix chiptune beeps with acoustic chimes within the same pack).
2. **Turn Clock Ticking (< 5 seconds) (Feedback Item 14)**:
   - Provide a specialized `playClockTick(remainingSeconds: number)` method.
   - Designed to play an urgent, crisp tick tone when the remaining turn clock drops strictly below 5 seconds (5, 4, 3, 2, 1).
   - Ensure the tick tone matches the active sound pack aesthetic.
3. **Volume & Sound Pack State Management (Feedback Item 7)**:
   - Provide methods in `SoundEngine` to:
     - Get and set master volume (`setVolume(v: number)` where `0 <= v <= 1`, default 0.7).
     - Get and set active sound pack by ID (`setSoundPack(packId: string)`).
     - Persist user volume and pack selection in `localStorage` under `durak_sound_pack` and `durak_sound_volume`.
   - Ensure audio operations are resilient to browser autoplay policies (resume `AudioContext` on first user interaction).

## Acceptance Criteria
