# Fix Gameplay Name Clipping, Deck Count Badge Overlap, and Light-Theme Action Button Contrast

## Context & Observed Defects
Real Chromium visual QA (`visual_qa_telemetry.json`, `totalGeometryIssues: 25`) and screenshot inspection revealed four objective layout, overlap, and contrast defects in the live gameplay and waiting-room screens:

1. **Horizontal text clipping in the `PLAYERS` sidebar (`21` `TEXT_CLIPPED_HORIZONTALLY` issues):**
   - In `frontend/src/app.css`, `.status-badge` uses `grid-template-columns: minmax(0, 1fr) auto minmax(0, 1fr);` and `.status-name` sets `overflow: hidden; text-overflow: ellipsis; white-space: nowrap;`.
   - Because the third column always reserves an equal `1fr` track even when `.status-state-slot` is empty, `.status-name` is starved to `clientWidth: 71px` inside the `272px` left sidebar.
   - Observed in `step_4`, `step_13`–`step_15`, `step_16`, and `step_17`–`step_22`: even the default guest name `"Guest-2R00 (You)"` (`scrollWidth: 113px` vs `71px`) clips to `"Guest-2..."`, `"QA Opponent 1"` (`100px` vs `71px`) clips to `"QA Oppo..."`, and in `step_16` both `"QA Spectator One"` (`117px` vs `71px`) and `"QA Spectator Two"` (`115px` vs `71px`) clip identically to `"QA Spec..."`.

2. **Horizontal text clipping in opponent seat boxes (`4` `TEXT_CLIPPED_HORIZONTALLY` issues):**
   - In `frontend/src/styles/table.css`, `[data-zone='table-arena']` uses `grid-template-columns: 1fr 2fr 1fr;`. In 3- and 4-player layouts (`step_16_item_3_m1_spectator_table.png`), `top-left` and `top-right` seats shrink from `--seat-width: 240px` to `193px` wide, clipping both `"QA Spectator One"` (`scrollWidth: 161px` vs `clientWidth: 139px`) and `"QA Spectator Two"` (`160px` vs `139px`) to identical `"QA Spectator..."` strings.
   - In `step_4_item_6_quick_pair_matched_game.png`, `"QA Quick Pair Opponent 1"` (`234px` vs `186px`) also clips horizontally inside `.opponent-name`.

3. **Talon count badge (`span.talon-count`) overlaps the `"DECK"` heading:**
   - Directly visible in `step_4`, `step_13`, `step_16`, and `step_17`: inside `[data-zone='table-deck']`, `gap: 10px` separates `<h2 class="deck-title">Deck</h2>` from `.deck-assembly`, while `.talon-count` applies `transform: translate(-14px, -14px)` (`frontend/src/styles/table.css`). Because `14px` exceeds the `10px` gap, the `"24"` / `"28"` badge overlaps and obscures the bottom of `"DECK"`.

4. **Low-contrast `"Copy link"` button in Light theme (`WaitingForPlayers`):**
   - Directly visible in `step_8_item_1_create_a_game_redirected.png` (`/g/HdCpwpy2`): `button[data-testid="copy-invite"].action-button` inherits `.action-button { background: var(--durak-border); color: #f5f1e6; }` from `frontend/src/styles/table.css`. In Light theme `--durak-border` is `#b9c2ce`, rendering off-white text on pale cool grey.

## Required Changes
1. **`frontend/src/app.css` (`.status-badge`, `.status-name`):**
   - Prevent `.status-name` from being clipped to `71px` when names are standard length (such as `"Guest-2R00 (You)"` or `"QA Spectator One"`):
     - Allow `.status-name` to wrap cleanly (`white-space: normal; overflow-wrap: anywhere; overflow: visible; text-overflow: clip;`) or give `.status-badge` tracks that don't waste half the row on an empty `.status-state-slot` while preserving `.status-cards` alignment and existing `GameTable` / `app.test.tsx` layout invariants.
   - Add Light-theme high-contrast styling for neutral `.action-button` controls (matching `.game-page .back-to-lobby`: `#e2e8f0` background, `1px solid #64748b` border, `#0f172a` text, `#cbd5e1` hover) so `"Copy link"` and any other neutral `.action-button` are legible in Light mode (`:root[data-theme='light']` and `@media (prefers-color-scheme: light)`).

2. **`frontend/src/styles/table.css` (`[data-zone='table-arena']`, `.opponent-name`, `[data-zone='table-deck']` / `.talon-count`):**
   - Ensure desktop outer opponent seat columns do not collapse below `--seat-width` when the arena has room (e.g., `grid-template-columns: minmax(240px, 1fr) minmax(0, 2fr) minmax(240px, 1fr);` on desktop above `899px`, or `minmax(240px, auto)` when seats fit within the `788px` inner width) so all opponent boxes stay uniform at `240px` (`Item 15`).
   - Allow `.opponent-name` to wrap cleanly across lines (`white-space: normal; overflow-wrap: anywhere; overflow: visible; text-overflow: clip;`) instead of horizontal `overflow: hidden` clipping, so long opponent names like `"QA Spectator One"` / `"QA Spectator Two"` and `"QA Quick Pair Opponent 1"` remain distinguishable without triggering `TEXT_CLIPPED_HORIZONTALLY`.
   - Fix the `"DECK"` / `.talon-count` overlap inside `[data-zone='table-deck']`: add sufficient top clearance on `.deck-assembly` (or increase `gap` / add `padding-top` >= `16px` on `.deck-assembly` / `.talon-deck`) so `.talon-count`'s `translate(-14px, -14px)` never intersects `h2.deck-title`.
