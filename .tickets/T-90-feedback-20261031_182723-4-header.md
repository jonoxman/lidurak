# Ticket T-90-feedback-20261031_182723-4: Global Site Header Bar, Navigation Menus, Connection Tracker, and Appearance/Audio Dropdown Settings

## Subsystem
Frontend Shell & Header Navigation (`frontend/src/components/HeaderBar.tsx`, `frontend/src/app.tsx`, `frontend/src/state/settings.ts`)

## Wave
WAVE:2 (Builds on Wave 1 Sound Engine and Texture/Card assets; runs concurrently with Ticket 5)

## Description & User Requirements
Implement the universal site header bar and the multi-tier profile dropdown customization system:
1. **Universal Header Bar Structure (Feedback Item 6)**:
   - Mount a header bar at the top of every page (`LobbyPage` and `GamePage`).
   - **Shading & Gradient (6d)**: Header bar must have a slightly different shade from the rest of the page. The rest of the page background must seamlessly transition via a subtle gradient from the header shade to the main background.
   - **Logo Link (6a)**: On the left end, display the "LIDURAK" logo as a link to home (`#/` or `navigate('/')`), with floating left margin spacing. On mouse hover, it interactively changes color.
   - **Navigation Menus (6b)**: Next to the logo, render 4 dropdown menus: "PLAY", "PUZZLES", "LEARN", and "WATCH". Each menu opens automatically on mouse hover and contains placeholder navigation links.
   - **User Profile Area (6c)**: On the far right with floating right margin spacing, display a placeholder username and an SVG user profile icon (person in circle). It lights up in a distinct color on hover (different from the logo link color).
2. **Profile Dropdown Menu (Feedback Item 6c)**:
   - Clicking the user profile button toggles an extensible dropdown menu containing:
     - Profile (with icon)
     - Inbox (with icon)
     - Preferences (with icon)
     - Sign out (with icon)
     - Language (with icon)
     - Sound (with icon & right-facing green chevron)
     - Theme (with icon & right-facing green chevron)
     - Table (with icon & right-facing green chevron)
     - Card Back (with icon & right-facing green chevron)
   - **Connection Tracker (6c)**: At the bottom of the profile dropdown, display:
     - Current Ping in ms (e.g., "Ping: 24 ms") on the left.
     - Server Delay in ms (e.g., "Server Delay: 12 ms") on the left.
     - An animated 4-bar signal strength indicator on the right side that dynamically reflects connection health.
3. **Sound Settings Submenu (Feedback Item 7)**:
   - Clicking the "Sound" item opens a secondary submenu with a right-facing green chevron indicator.
   - Features an interactive master volume slider connected to `SoundEngine.setVolume()`.
   - Displays clickable options for the 5 sound packs ("Classic Felt", "Arcade 8-Bit", "Sci-Fi Synth", "Acoustic Pluck", "Modern Minimal"). Hovering over sound pack options highlights them in a pale version of the primary site green.
4. **Theme & Roundness Settings Submenu (Feedback Item 8)**:
   - "Theme" profile item features a right-facing green chevron.
   - Secondary submenu allows choosing between "Device theme", "Light", and "Dark".
     - Dark theme matches the existing dark aesthetic.
     - Light theme delivers a cohesive, elegant light durak palette.
     - Device theme tracks OS `prefers-color-scheme`.
   - Interactive **Roundness Slider**:
     - Defaults to `8px` and scales from `0px` to `16px`.
     - Controls a global CSS custom property `--app-roundness` (or `--border-radius-base`), making elements completely square at `0px` and rounded at `16px`.
   - Hover highlight uses the pale green accent.
5. **Table Texture Settings Submenu (Feedback Item 9)**:
   - "Table" profile item features a right-facing green chevron.
   - Secondary submenu displays a grid of previews for the 6 table textures created in Ticket 3.
   - Includes 3 real-time interactive sliders: **Brightness**, **Contrast**, and **Hue**, dynamically updating the felt appearance in real time.
6. **Card Back Settings Submenu (Feedback Item 10)**:
   - "Card Back" profile item features a right-facing green chevron.
   - Secondary submenu displays a grid view of the 6 card back patterns created in Ticket 3 with active selection indicator.
